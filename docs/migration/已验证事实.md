## 4. 已读取的高风险功能事实（S）

### 4.1 计费/usage/Model Plaza（静态切片）

- Personal `backend/internal/service/billing_service.go:93-120` 的 `ModelPricing` 保留显式 0 语义和 `LongContextInputThresholdPresent`；Personal 还分别处理 Fast/priority、Flex、max reasoning 和 long-context。
- 官方 `backend/internal/service/billing_service.go:1676-1792` 可见 `applyModelSpecificPricingPolicyEx` 与 `longContextMultiplierOrOne` 等定价策略实现。二者不能直接整段覆盖，否则可能丢失 Personal 显式 0、请求级快照或渠道倍率语义。
- Personal `backend/internal/service/openai_gateway_usage.go:183-214,375-429,499-520` 的 `RecordUsage`/统一账务链拆分 input/cache 并使用价格快照、用户/组倍率；融合必须保持 usage 单写和幂等。
- 官方 `backend/internal/service/model_plaza_service.go:60-101,345-380` 输出官方参考价、阶梯/分时信息；Personal `backend/internal/service/channel_plaza.go:21-54,239-294` 已有渠道/分组/图片/时段价语义。计划方向是展示参考增量，不是覆盖 Personal 计费。
- 官方 `backend/internal/handler/admin/account_upstream_billing_rates.go:16-29,73-89` 体现读取/分页/ETag/API 合同，不能从该接口文本推导产品收费数字。
- 未验证：官方准确 0.2.1→0.2.4 历史差异、所有 provider、运行时路由、真实倍率来源、数据库和运行态。

- 官方 `frontend/src/views/admin/groupModelAllowlist.ts:1-4,11-15,131-138` 的配置形状为 `enabled` 与 `models: string[]`；候选请求/跟踪器在 `frontend/src/views/admin/modelAllowlistCandidates.ts:5-9,16-38`，按 mode/group/platform 抑制过期结果。
