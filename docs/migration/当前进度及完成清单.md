### 状态语义

- **已锁定**：只表示路径、分支、HEAD、文件 hash 或计划边界已记录。
- **静态确认**：只表示从指定文件读取到符号/文本；不表示编译、测试、运行或数据库正确。
- **已实施**：代码或文档已经落盘；不表示通过。
- **局部 PASS**：限定同一候选、package/tag/regex/命令和时点的通过；不能代签整体门禁。
- **COMPILED_NOT_RUN**：仅编译，不是测试 PASS。
- **BLOCKED / UNKNOWN**：缺少来源、权限、fixture、运行条件或白名单路径；不得用猜测补齐。
- `G_CODE=PASS`、`G_DB=PASS`、可发布、可提交、真实资金/外部调用，分别独立签署。

不能因为迁移 SQL mock、只编译、旧隔离专项或文件结构静态相同而提前签 `G_DB`。G_DB 必须绑定获准目标和恢复证据，并独立记录数据差集、约束/索引、事务、锁、重启、账务守恒、权限和外部副作用。
